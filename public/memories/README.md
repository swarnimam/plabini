# Memories photo folder

**This is the only folder you need to edit to change the Memories album.**

- Add, replace, rename or delete images directly in `public/memories/` on GitHub.
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif` (case-insensitive).
- Photos are discovered automatically during the next website build/deployment. There is no photo list or source code to edit.
- Files appear in natural filename order. Prefix filenames with `01-`, `02-`, etc. to control the sequence.
- Descriptive filenames become accessible photo captions: `01-family-haldi.webp` becomes “family haldi”.
- For fast loading, prefer WebP or compressed JPEGs, ideally around 1600–2000 pixels on the longest side and under 500 KB per image.
- Removing every image is safe: the album shows an empty-state message.
